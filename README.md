# 砧边声学助手（Forge Ear）

放在砧子边上的学徒辅助小工具：**实时听锤声 → 检测每一锤 → 提取坯料振动频率与衰减 → 估算温度与剩余可打锤数 → 提示暗裂**。

- 锤击检测与频率提取全部在 **AudioWorklet** 实时线程中完成
- 音频采集用 **Web Audio API**，其余逻辑用 **TypeScript**
- 四个页面：实时监听、锤击记录、温度曲线、标定管理
- 自带**合成测试录音生成器**（多种钢材/坯料尺寸/温度/暗裂 + 鼓风机与远处锤声干扰），无需真实录音即可回归验证

## 快速开始

```bash
npm install
npm test        # 跑合成录音验收测试（9 项指标）
npm run dev     # 启动开发服务器，浏览器打开后用「播放合成演示」即可体验
npm run build   # 类型检查 + 生产构建
```

浏览器里没有麦克风也能用：实时监听页点 **「播放合成演示」**，会现场合成一段含暗裂锤的锻打录音并走完整分析管线。

## 工作原理

### 1. 锤击起始检测（`src/dsp/onset.ts`）

- 512 样本滑动帧、128 跳幅（≈2.7ms 精度）
- 主判据是**频谱通量（spectral flux）**：锤击瞬态让全频带能量同时跃升，而鼓风机是平稳低频轰鸣，RMS 难以区分但通量差异显著
- 自适应噪声底（EMA）+ 绝对 RMS 门，排除远处弱锤声
- **谱门控**：用高频瞬态带（1.5k–8k）能量占比区分近场锤击与鼓风机/远处锤声
- 110ms 不应期，保证 3 锤/秒（间隔 333ms）也能逐锤分开

### 2. 频率与衰减提取（`src/dsp/features.ts`）

- onset 后取 48ms 分析窗，16384 点 FFT（零填充，bin≈2.93Hz）
- 模态搜索带 300–4200Hz，物理隔离砧子回响（185/277Hz 固定音），最低频强峰即坯料基频 f1
- 抛物线插值做亚 bin 测频
- **频率分裂检测**：在每个模态 ±6% 邻域内找双峰，要求峰间有明显凹陷（区分裂纹分裂与单峰旁瓣）
- **Goertzel 逐子帧测幅 → log 线性拟合**求衰减时间常数 tau（坯料越热、弹性模量越低，f1 越低、tau 越短）
- 暗裂综合评分 = 频谱分裂（主证据）+ 时域拍频 + 包络拟合残差

### 3. 温度估算（`src/dsp/temperature.ts`）

- 有 ≥3 个测温枪标定点：在 (f1, tau1) 二维空间做距离加权局部岭回归
- 标定不足：基于弹性模量温度系数的物理兜底公式
- 剩余锤数：按近期降温斜率外推到回炉阈值（默认 720°C）

### 4. 抗干扰

鼓风机建模为 55/92Hz 低频轰鸣 + 强低通气流噪声，远处锤声建模为低幅闷响，二者在谱门控下均不产生锤击记录。可在界面上开关谱门控对比效果。

## 验收指标（合成测试录音）

`npm test` 在 10 组「钢材 × 坯料尺寸」会话（共 204 锤，含 3 锤/秒快节奏）+ 暗裂专项 + 纯干扰专项上验证：

| 指标 | 要求 | 实测 |
| --- | --- | --- |
| 锤击起始检出率 | ≥ 98% | **100%**（204/204） |
| 温度误差 P95 | ≤ 40°C | **0°C**（MAE 0，最大 1°C） |
| 暗裂检出率 | ≥ 85% | **88.5%**（46/52） |
| 暗裂误报率 | ≤ 5% | **0%**（0/312） |
| 锤击→轻量提示延迟 | ≤ 100ms | **≈25ms** |
| 锤击→完整特征延迟 | ≤ 100ms | **≈73ms**（20ms 门控 + 48ms 分析窗 + 调度） |
| 3 锤/秒逐锤分离 | 全部分开 | **100%**（30/30） |
| 纯干扰环境误报 | 0 | **0**（鼓风机 + 14 次远处锤声） |

> 说明：温度误差在合成录音上接近 0，是因为合成器与标定共用同一物理模型。真实部署时误差来自建模偏差与环境噪声，**必须用测温枪在现场重新标定**（标定管理页支持逐点录入），兜底公式仅在未标定时使用。

## 真实部署的标定流程

1. 标定管理页选好钢材与坯料尺寸
2. 测温枪测坯料温度，同时打一锤
3. 把实时页读出的 f1、tau 连同温度录入，在 750–1250°C 间取 5–6 个点
4. 此后该钢材+尺寸组合的温度估算即走标定曲线
