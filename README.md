# 铁匠之耳 · Smith Ear

放在砧子边的实时听音工具：用 Web Audio API 采麦，在 **AudioWorklet** 中完成锤击起始检测、坯料模态频率/衰减提取和暗裂特征判断；主线程 TypeScript 负责温枪标定、温度推断、可打锤数、记录、曲线与管理页。

> 指标来自仓库内置的合成锤声数据集（9 种钢/尺寸组合 × 40 锤，共 360 个目标锤击，含鼓风机、远处锤声和 3 锤/秒连续锻打）。真实麦克风、砧子和房间会改变频响，首次现场使用请用测温枪补标 5–10 个点。

## 启动

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的地址，建议使用桌面版 Chrome/Edge。进入“实时监听”，选择麦克风和当前钢材/坯料，点击“开始实时监听”并授权麦克风。

生产构建：

```bash
npm run build
npm run preview
```

## 四个页面

1. **实时监听**
   - 大字号温度、“还能打几锤”、停锤/回炉/暗裂警报。
   - Worklet 延迟、匹配模态、衰减 τ、裂峰分数。
   - 实时频谱/波形/电平表、最近锤击和排除事件数。
2. **锤击记录**
   - 按可打、偏少、过冷、暗裂、已排除筛选。
   - 每锤的模态、分裂双峰、τ/R²、温度置信度和延迟。
   - CSV/JSON 导出、单条删除、清空。
3. **温度曲线**
   - 按时间绘制推断温度和最低锻造温度线。
   - 暗裂锤用红色标记，展示最近温降速度。
4. **标定管理**
   - 3 种钢：1095、5160、O1。
   - 3 种尺寸：小刀坯、厨师刀、厚重刀坯。
   - 已预置按物理热软化模型生成并加入测量噪声的温枪标定点。
   - 可录入现场温枪读数，或直接取最近一锤的模态/衰减特征。
   - 可试听正常/暗裂合成锤声，也可在浏览器跑合成自检。

## 音频与检测链路

```text
麦克风
  └─ Web Audio API getUserMedia（关闭 AEC/NS/AGC）
      └─ GainNode / AnalyserNode（Analyser 只负责可视化）
          └─ AudioWorklet: hammer-ear-processor
              ├─ 620 Hz 一阶高通能量 + 190 Hz 低频能量
              ├─ 自适应噪声底、突增沿、近场强锤/远锤双阈值
              ├─ 2048 样本模态窗口（48 kHz 下 42.7 ms，有效后锤段约 37 ms）
              ├─ Radix-2 FFT + 谱底显著性选峰
              ├─ 局部加窗 DTFT 精修频率
              ├─ 分帧复相关/对数包络拟合 τ 与 R²
              └─ 局部密集 DTFT 搜索 19–112 Hz 双峰、谷深和拍频不规则度
                  └─ postMessage(DetectedStrike)
                      └─ TypeScript 标定匹配/温度/裂纹复核/Store/UI
```

### 排除鼓风机和别人打铁

- 鼓风机主要是低频隆隆声和电机调制，起始判定看 620 Hz 以上瞬态能量。
- 远处锤声更闷、峰值更低；检测器把“候选起始”和“近场强锤保护”分开，避免远锤后的长保护期压住后面的砧边真锤。
- 固定砧子共振 `1765 / 2648 / 3972 / 5280 Hz` 会作为已知干扰线，不参与暗裂双峰判定。
- 最终还要匹配当前钢种/尺寸的至少两个坯料梁模态；不匹配的声音标记为 `rejected`，不会给温度和可打锤数。

## 温度和可打锤数

坯料模态频率按自由-自由矩形梁建模：

```text
fₙ ∝ Kₙ² · thickness / length² · √(E(T) / ρ)
E(T)/E₀ = 1 − aΔT − bΔT²
```

温度升高 → 弹性模量下降 → 频率降低，同时内阻尼增大 → τ 缩短。标定点保存温枪温度、模态频率和 τ；推断时以稳定的频率缩放插值为主，衰减 R² 足够高时才加入最多 7% 的阻尼权重。

可打锤数根据当前温度到该钢种最低锻造温度的余量，以及尺寸的每锤热损失 + 等待间自然冷却估算；同一把刀有 4 锤以上记录后，会用近期温度斜率修正经验损失。

## 合成锤声

`src/core/synth.ts` 直接合成：

- 锤头：高通噪声瞬态 + 2.3–6.3 kHz 短寿命金属点击；
- 砧子：固定模态和独立 τ；
- 坯料：前 3–4 个自由梁模态，频率由钢种、尺寸和温度决定；
- 热态：频率下降、τ 缩短；
- 暗裂：一个或两个模态分裂成近距双峰，双峰 τ 不同并带拍频/不规则调制；
- 环境：低频鼓风机/电机声，以及带低通和反射回声的远处他人锤声。

## 真实现场校准建议

1. 第一次使用时先在“标定管理”选择最接近的钢种和尺寸。
2. 用测温枪在 1050、950、850、760、700 °C 左右各录 2–3 锤；在新增温枪读数里点“取最近一锤特征”，填温度后保存。
3. 测温枪发射率建议按氧化钢表面设在约 0.85–0.95，并保持距离一致。
4. 麦克风避免直对鼓风机风口；可放在砧座附近耐热、防震的位置。
5. 如果真实砧子共振与默认 `ANVIL_MODES_HZ` 差别很大，可先录几锤正常声，把稳定不随温度移动的峰加入砧子频率表；当前版本在 `src/core/physics.ts`。
6. 暗裂提示是声学筛查，不是无损检测结论；报警后应停锤并做外观、喷砂、磁粉或后续热处理检查。
